# Ricardo Lara — versão premium

1. Extraia o ZIP e envie os arquivos extraídos para a raiz do repositório no GitHub, mantendo `assets`.
2. O `index.html` deve ficar na raiz, junto de `styles.css`, `script.js` e `vercel.json`.
3. Na Vercel, importe o repositório. Framework: Other; comando de build vazio; saída: `.`.
4. Não crie uma pasta `public` ou `dist` em volta destes arquivos. O `vercel.json` já define a configuração estática.

`ALTERACOES_PREMIUM.md` explica cada edição e inclui o diff completo. `premium.patch` permite reverter as edições de HTML/CSS/JS.

Fonte Inter e GSAP/ScrollTrigger ficam hospedados localmente em `assets`; preserve suas licenças.
